## Purpose

`barprofiles_figures_for_paper.py` is a plain-Python adaptation of the original Erwin bar-profile paper figure-generation code. It produces the main analysis plots used to compare bar/profile classifications, galaxy properties, and B/P-related frequencies for S4G galaxies.

The script combines:

- S4G galaxy catalogue data.
- Bar/profile classification files.
- Sample membership files for the moderate-inclination and face-on subsamples.
- FITS image cutouts for selected isophote/profile examples.
- Local plotting and analysis helper modules.

## How to run

From the repository root:

```powershell
python "Erwin_barprofiles_paper_GB_working_copy\barprofiles_figures_for_paper.py"
```

The script uses Matplotlib's non-interactive `Agg` backend, so it can run without opening plot windows.

## Main inputs

The script expects these files under `Erwin_barprofiles_paper_GB_working_copy/data`:

- `s4gbars_table.dat`: main S4G bar-profile catalogue.
- `s4gbars_bp-buckling_profiles_checklist.dat`: moderate-inclination B/P detection sample.
- `s4g_faceon_names.dat`: face-on comparison sample.
- `classifications_pe.txt`: PE profile classifications.
- `classifications_vd_revised.txt`: VPD profile classifications.
- `scrambled_map.txt`: mapping used by the classification utilities.

The script also uses FITS images from:

- `Erwin_barprofiles_paper_GB_working_copy/data/images`
- `Erwin_barprofiles_paper_GB_working_copy/external_images`

Only a few FITS images are included in the repository. If the optional `external_images` archive is missing, the corresponding isophote/profile examples are skipped.

## Local helper modules

The script imports several modules from the same source folder:

- `datautils.py`: reads the composite catalogue table.
- `angle_utils.py`: deprojection and position-angle calculations.
- `plotutils.py`: contour plotting, profile extraction, arrows, PA lines, and frequency plots.
- `barprofile_utils.py`: classification loading and dictionary/index construction for profile classes.

## Helper functions in the script

### `savefig(*args, **kwargs)`

Wrapper around `matplotlib.pyplot.savefig`.

It sets consistent PDF margins with:

```python
bbox_inches="tight"
pad_inches=0.08
```

It also avoids saving an isophote/profile PDF if the source FITS image was unavailable.

### `GetYLimits(radii, intensityProfile, ZP=None)`

Calculates sensible y-axis limits for radial intensity or surface-brightness profiles.

If `ZP` is `None`, it treats the profile as intensity and returns logarithmic-style limits. If `ZP` is supplied, it converts intensities into surface brightness in mag arcsec^-2 and returns inverted magnitude-axis limits.

### `MakeIsophoteAndProfilePlots(...)`

Creates a two-panel figure for an individual galaxy:

- Left panel: image contours with bar major axis, bar minor axis, and optional B/P feature marker.
- Right panel: deprojected bar-major and bar-minor radial profiles.

It reads FITS image data, applies a median filter, extracts profiles using `plotutils.GetProfileAtAngle`, deprojects radii with `angle_utils`, and returns the Matplotlib figure.

If the image file does not exist, it prints a skip message and does not save a PDF for that galaxy.

### `GetNames(filename)`

Reads a sample membership file and returns the galaxy names that are not commented out or disabled.

### `logistic(x, a, b)`

Computes the logistic function:

```python
1.0 / (1.0 + np.exp(-(a + b*x)))
```

This is used for the frequency/fraction plots.

## Processing flow

1. Configure Matplotlib, local paths, input data, and output folder.
2. Read `s4gbars_table.dat` into `s4gdata`.
3. Define the moderate-inclination and face-on samples.
4. Generate selected galaxy isophote/profile examples.
5. Generate stellar-mass histograms for the overall and subsample selections.
6. Load PE and VPD classifications with `barprofile_utils`.
7. Generate stellar-mass distribution plots by profile class.
8. Generate distributions for Hubble type, gas fraction, colour, relative bar size, and bar-strength measures.
9. Generate logistic/frequency plots for B/P morphology and P+Sh profile occurrence.
10. Save all enabled plots as PDFs in the Erwin `barprofiles_plots` folder.

## Notes and limitations

- This is a script-style program, not a command-line tool. Most configuration is set directly inside the Python file.
- `savePlots` controls whether PDFs are written.
- The output path is absolute and points to the Erwin Dropbox research folder.
- Missing optional FITS files do not stop the whole run; those specific image plots are skipped.
- The script depends on local helper modules in the same folder, so it should be run from the repository environment rather than copied out on its own.
