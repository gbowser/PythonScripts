# Project continuity

The user works on a desktop PC and a laptop using separate VS Code Codex histories.

- Read `PROJECT_HANDOVER.md` before starting substantive work in this repository.
- Keep it current whenever work changes project decisions, implementation status,
  setup requirements, known limitations or next steps. Update it before finishing
  the task, including when work remains incomplete.
- Record concrete file locations and validation results. Distinguish completed,
  tested work from proposals and unverified assumptions.
- Preserve unrelated project notes; keep entries concise and remove stale status.
- Do not put credentials, tokens or private authentication files in the handover.
- The handover travels between computers only after it is committed, pushed and
  pulled. Do not claim it is on GitHub without checking; this instruction does
  not itself authorize committing or pushing changes.
